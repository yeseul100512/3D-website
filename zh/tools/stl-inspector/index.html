发现的问题

  • 开放边（孔洞）

    这里的表面没有封闭，切片软件只能猜测实体的边界。小缝隙通常会被自动封闭；大孔洞可能造成缺层，或者把本该留空的地方填上。

  • 非流形边

    一条边上连接了三个或更多的面。这里无法分辨内外，切片软件可能少打或多打材料。

  • 翻转面

    周围的面朝外，而这些面朝内。切片软件可能把这一块当成孔洞，或者把内外弄反。

  • 零面积三角形

    没有面积的三角形（退化成线或点）。它们对形状没有贡献，但可能干扰修复算法。

  • 重复面

    同一个三角形被保存了不止一次，该处表面出现了双层。

  • 无法读取的三角形（NaN / Inf）

    这些三角形的坐标不是有效数字，加载时已被排除，原位置可能留下孔洞。

  • 文件被截断

    文件在声明的三角形全部写完之前就结束了，很可能是下载或导出中断所致，这里只显示完整的部分。如果可以，请重新获取文件。

薄壁（估算）

从表面上均匀分布的 2 万个点向零件内部投射光线，测量到对面壁的距离。比两倍喷嘴直径还薄的壁往往打印得很脆弱，甚至打不出来。这是估算，不是精确测量。

    这个工具能做什么

    本工具读取 STL、3MF 和 OBJ 文件，给出尺寸（毫米）、三角形数量、表面积、体积和独立壳体数量。它会检查零件能否直接放进所选打印机的成型范围、是否需要换个方向摆放，或者超出多少；如果尺寸看起来像是按英寸或米保存的，也会提醒您。

    接着查找会让切片软件出错或自行猜测的问题：按孔洞归组的开放边、被三个以上面共用的边、朝向翻转的面、面积为零的三角形和重复面、无法读取的坐标，以及被截断的文件。每种问题都给出数量和它对打印的影响说明，点一下按钮即可在 3D 视图中高亮并放大到对应位置。

    所有修复都是可选的，并且逐项单独应用：合并几乎重合的顶点、删除损坏的三角形、把面的朝向统一为向外，以及逐个选择要封闭的孔洞，这样有意留出的开口可以保持不变。修复后会重新检查并对比前后数量，同时显示包围盒在 0.001 mm 精度内是否保持不变。结果可保存为 STL、3MF 或 OBJ，因此也可以当作格式转换器使用；所有已加载文件的表格可以保存为 Excel 或 CSV。

    使用方法

    1. 把一个或多个 STL、3MF、OBJ 文件拖到方框里，或点击方框选择文件。
    2. 查看判定结果和尺寸。如果尺寸看起来差了 25.4 倍或 1000 倍，展开“更改单位”，一键重新缩放。
    3. 选择打印机或手动输入成型范围，查看零件能否放下。
    4. 在“发现的问题”中点击某项旁边的“显示”，3D 视图会高亮并放大到该位置。
    5. 需要修复时，只勾选想要的修复项和要封闭的孔洞，然后点击“应用所选修复”。对照前后对比表，不满意可以用“撤销全部修复”恢复到加载时的状态。
    6. 把网格保存为 STL、3MF 或 OBJ，或把全部文件的表格保存为 Excel 或 CSV。

    限制与注意事项

    • 无法修复自相交（表面互相穿过）、没有厚度的壁，以及本身设计有误的模型。这些问题需要回到 CAD 或建模软件中解决。
    • 孔洞只用其边缘上的点生成平面补片来封闭。这适合小缝隙和平面开口；曲面上的孔会被平盖封住，而不是还原原来的曲面。超过 2,000 条边的孔洞和不成闭合环的边界只会报告，不会封闭。
    • 合并顶点时，顶点最多可能移动一个容差的距离，比容差更小的三角形会被压扁消失，因此请保持较小的容差（默认 0.001 mm）。
    • 薄壁数值是根据表面上均匀分布的 2 万个采样点估算的，并非对每一处壁厚的测量。采样点之间的薄处可能被漏掉，而楔形尖锐边缘的尖端总会被判为过薄。
    • 只有网格完全封闭时体积才可靠，否则会标注为不可靠。
    • 打印范围判断只比较包围盒沿坐标轴摆放的各个方向，不考虑斜放，也不考虑裙边、Brim 和擦料区域。
    • 三角形超过约 500 万个时会关闭 3D 视图，只显示数值；超过约 400 万个时跳过薄壁检查。能打开多大的文件取决于设备内存。
    • 3MF 只读取几何形状。保存时不会保留颜色、材料、打印设置和盘面布局，文件中的多个对象会合并成一个网格一起检查。

    常见问题

    文件会上传到服务器吗？

    不会。文件只在您的浏览器中读取和处理，不会发送到任何地方，也没有排队和时间限制。

    和切片软件的自动修复有什么不同？

    自动修复会一次性修掉所有问题，却不告诉您改了什么，有意留出的开口可能被填上，形状也可能在不知不觉中改变。本工具先让您看到每个问题的位置，再由您自己选择要修复的项目，修复后给出前后数量和包围盒的对比。

    “非流形（non-manifold）”是什么意思？

    指一条边被三个或更多的面共用，例如边上多出一片薄片，或两个实体只沿一条边相连。真实的实体每条边恰好连接两个面，所以切片软件在这种位置无法分辨内外。

    显示有开放边，但打印一直正常，这算问题吗？

    通常不算。切片软件会自行封闭小缝隙，所以轻微问题的判定是“切片软件很可能会自动修复”。大孔洞和非流形边才容易造成缺层或开口被填，请在切片预览中检查这些位置。

    能把 STL 转成 3MF 或 OBJ 吗？

    可以。加载文件后，在“保存网格”中点击想要的格式即可，不必应用任何修复，单位为毫米。

    尺寸小了 25.4 倍（或 1000 倍），为什么？

    STL 文件不带单位信息。按英寸或米导出的文件也会被当作毫米读取，所以显得很小。请在“更改单位”中乘以 25.4 或 1000，然后重新保存。

    最大能打开多大的文件？

    150 MB 的二进制 STL（300 万个三角形）在普通笔记本上几秒钟就能检查完，并显示 3D 视图。500 MB（1000 万个三角形）的文件在内存充足的台式机上也能检查，但只显示数值，不显示 3D 视图。
