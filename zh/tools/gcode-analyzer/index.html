G-code 分析器

放入切片后的文件，即可读取打印时间和耗材用量；工具还会把所有挤出动作逐一累加，核对文件头里的数值。

合计与导出

用这些数值计算成本

这个工具能做什么

打开切片软件生成的 G-code（.gcode、.gco、.g），或 Bambu Studio、OrcaSlicer 导出的 .gcode.3mf，把文件里记录的信息集中列出：预计打印时间，耗材的长度、体积和重量，层数与层高，喷嘴和热床温度，以及换料次数。

它不会只看文件头：工具会把每一次挤出（E）动作累加起来，重新算出耗材长度，并显示耗材分别用在了外墙、内墙、填充、支撑等哪些部分。如果文件头与实际挤出量相差较大，或文件头根本没有填写，会给出警告。

一次放入多个文件或多个打印板时会给出合计。结果可以复制、保存为 CSV 或 xlsx，也可以直接带到成本计算器。

使用方法

  1. 在切片软件中导出 G-code 或 .gcode.3mf，把文件拖到上方区域，或点击该区域选择文件。可以一次选择多个。
  2. 每个文件都会显示摘要、按耗材统计的表格和按特征统计的表格。需要留意的问题会以警告的形式显示在表格上方。
  3. 用下方的按钮复制结果，或保存为 CSV、xlsx。点击“用这些数值计算成本”，会打开成本计算器并自动填入重量和时间。

限制与注意事项

  • 打印时间是切片软件写入文件的数值，本工具不会另行预测。实际耗时会因换料所需时间、打印机的加速度上限，以及预热、热床调平等固件动作而与切片软件给出的数值不同。
  • 只有文件中写明了重量或密度时才会显示重量。像 Cura 这样只记录长度的切片软件，其文件只能得到长度和体积；文件中没有线径时，按 1.75 mm 计算。
  • 只有带 ;TYPE: 或 ; FEATURE: 注释的文件（Bambu Studio、OrcaSlicer、PrusaSlicer、Cura 等）才能按特征统计。起始 G-code 中的擦料线通常不计入切片软件的文件头，因此累加值可能略高于文件头。
  • 无法读取 PrusaSlicer 的二进制 G-code（.bgcode），请在切片软件中导出普通 G-code。使用固件回抽（G10/G11）或体积挤出（M200）的文件，累加出的长度可能不准。
  • 普通 G-code 是分块读取的，几十 MB 的文件也不会让页面卡住。.gcode.3mf 需要先解压到内存，特别大的文件在手机上可能打不开。

常见问题

为什么实际打印时间和切片软件给出的不一样？

切片软件是按一套加减速模型估算移动时间的，和打印机固件的实际动作不可能完全一致。预热、热床调平、换料和冲刷所需的时间也因机器和具体情况而异。本工具并不声称比切片软件预测得更准，只是如实显示切片软件写下的数值。

为什么“E 轴累加值”和文件头的数值略有出入？

文件头是切片软件算出来写入的数值，累加值则是把文件中实际的挤出指令加起来的结果。由于起始 G-code 的擦料线和四舍五入，两者通常相差不到 1%。如果相差超过 5%，文件可能被修改过或不完整，工具会给出警告。

可以统计多个打印板的合计吗？

可以。同时选择各个打印板的 G-code 文件，或放入包含多个打印板的 .gcode.3mf，每个打印板都会单独显示结果，最下方会显示时间和耗材的合计。

文件会被上传吗？

不会。文件只在当前浏览器内读取和计算。跳转到成本计算器时，也只是把重量和时间两个数字放在网址的 # 之后传递，浏览器不会把这部分发送给服务器。
