这个工具能做什么

模型会沿 X、Y、Z 方向按等间距的网格切开。块数是用成型尺寸减去边缘余量和榫头深度后计算的，所以带榫头的每一块都不会超出成型尺寸。切完后会重新测量每一块的实际尺寸，并在表格中标出是否放得下。

切面可以选择互相咬合的指接榫，也可以选择平面。榫头的宽度、深度和装配间隙都可以自己设定；沿多个方向切开时，会省去切面交汇处旁边的榫头，避免榫头互相重叠或出现脱落的细条。

每块的文件名都带有网格位置，例如 X1-Y2，并附带一张标注相同名称的拼装图。可以逐块下载 STL，也可以打包成 ZIP 一次下载。

使用方法

  1. 拖入 STL、3MF 或 OBJ 文件，或点击选择文件。页面会显示尺寸和三角形数量；如果网格有破洞，会给出警告。
  2. 输入打印机的成型尺寸（X、Y、Z）和边缘余量。
  3. 选择保持模型方向，还是旋转模型以减少块数。如果想自己决定块数，请选择“手动指定”。
  4. 选择切面方式后点击“开始分割”。页面会显示进度，随时可以取消。
  5. 在表格中确认每块的实际尺寸和是否放得下，然后下载 STL 或 ZIP。拼装时按拼装图上的名称对位即可。

限制与注意事项

  • 切割位置不能自选，始终是与坐标轴平行、间距相等的平面。如果需要避开细节或斜着切，请使用 CAD 软件或切片软件的切割功能。
  • 模型必须是没有破洞的封闭网格。如果存在开放边，工具会给出警告并继续切割，但切出的块可能是空心的或缺面。切出的块上常会留下只有一侧被分割的边（T 形接缝），因此网格检查工具（包括本站的检查工具）会把它们报告为开放边。这些缝隙宽度为零，切片软件通常会自动缝合，但打印前请务必在切片软件的预览中检查。
  • 指接榫只能防止两块沿切面的一个方向滑动，不能抵抗拉开的力，所以需要用胶水粘合。沿 Z 方向上下切开时，上面一块的榫头朝下，需要支撑，这种情况建议用平面切割。
  • 0.3 mm 的装配间隙是针对普通 FDM 打印机的起始值。不同的打印机和材料可能偏紧或偏松，建议先用小块试打。榫头宽度会略作调整，使其正好整数等分边长。
  • 各块按拼装后的位置保存，摆平和排版需要在切片软件中完成。单位按毫米处理。
  • 含有数百万个三角形的文件，切割可能需要几十秒到几分钟，并占用数 GB 内存。在手机上处理大文件可能失败。3D 预览和切割库在首次使用时从 CDN 下载，因此需要联网（模型文件不会被发送）。

常见问题

切出来的每一块真的放得下吗？

块数选择“自动”时，网格会把榫头伸出的长度一并计算；切完后还会重新测量每一块，并在表格中标出“放得下”或“超出”。如果手动指定了块数，可能出现超出的情况，请查看表格。

薄板模型会不会被竖起来切？

默认是“保持当前方向”，不会旋转模型。只有选择“旋转以使块数最少”时才会按 90° 旋转，并在结果中说明各轴的对应关系。

3MF 或 OBJ 文件也能切吗？

可以。支持读取 STL（二进制和 ASCII）、3MF 和 OBJ。如果文件里有多个物体，会合并成一个模型一起切，结果保存为 STL。颜色和切片设置不会保留。

装配间隙加在哪里？

加在每个榫头的两个侧面，每侧各留出所输入的间隙。榫头顶端与榫槽底部紧贴，没有间隙，所以拼装后的总长度与原模型相同。

文件会被上传吗？

不会。读取、切割和生成 ZIP 都在这个浏览器内完成。唯一需要下载的是用于 3D 显示和切割的公开库。
