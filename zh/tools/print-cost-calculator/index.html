这个工具能做什么

根据耗材重量和每公斤价格计算材料费。最准确的重量来自切片后的 G-code 或 .gcode.3mf；也可以从 G-code 分析器带过来，或直接手动输入。

对于尚未切片的 STL、OBJ、3MF 模型，会根据体积和表面积粗略估算重量。算法假设整个表面有一层厚度均匀的外壳，其余部分按填充率填充，因此结果与切片软件会有出入。

还可以按需加入电费、每小时设备损耗、失败余量和人工，再填入加价率和平台手续费得出售价。设置会保存在当前浏览器中，明细可导出为 CSV 或 xlsx。

使用方法

  1. 放入切片软件导出的 G-code 或 .gcode.3mf，重量和打印时间会自动填好。没有文件时，直接输入重量即可。
  2. 选择材料，并按手头的耗材修改密度和每公斤价格。
  3. 需要计算电费、设备损耗、失败余量、人工或售价时，展开对应的选项并填写数值。留空的项目不计入。
  4. 在下方表格中查看各项金额与合计，需要时保存为 CSV 或 xlsx。

限制与注意事项

  • 由 3D 模型得出的重量只是切片前的粗略估算，不包含支撑、帽檐、冲刷和顶底层数等因素。正式报价请使用切片后的 G-code。
  • 有孔洞或面朝向不一致的模型，其体积并不可靠，因此不会估算重量。请在模型检查工具中查看问题。
  • 材料的密度和价格只是常见数值的默认值。同一种材料也会因品牌和颜色而不同，请按耗材规格书修改。
  • 货币选项只改变符号和小数位数，不会按汇率换算金额。
  • 电费只是“平均功率 × 打印时间”的简单计算。打印时间是切片软件的估计值，可能与实际不同。不含税费和运费。

常见问题

为什么用 STL 估算的重量和切片软件给出的不一样？

STL 估算只考虑模型的体积和表面积。实际打印的耗材量还取决于墙层数、顶底层数、填充图案、支撑和帽檐，这些只有切片后才能确定。需要准确数值时，请放入切片后的 G-code。

售价是怎么算出来的？

先在总成本上加上加价率（%），再倒推出一个价格，使平台按售价比例扣除手续费后仍能拿到这笔金额：售价 = 总成本 ×（1 + 加价率）÷（1 − 手续费率）。

失败余量是按哪些费用计算的？

按材料费、电费和设备损耗之和乘以填写的百分比。例如大约每十次失败一次，就填 10%。人工不计入其中。

我填写的设置保存在哪里？

只保存在当前浏览器的本地存储中，不会发送到服务器。点击“重置设置”即可清除。
