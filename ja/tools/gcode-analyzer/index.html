G-code 解析

スライス済みのファイルを読み込むと、造形時間とフィラメント使用量を表示します。押し出し量を実際に合計し、ヘッダーの値が正しいかも確認します。

合計とエクスポート

この数値でコストを計算

このツールでできること

スライサーが出力した G-code（.gcode、.gco、.g）や、Bambu Studio・OrcaSlicer の .gcode.3mf を開き、ファイルに記録されている予想造形時間、フィラメントの長さ・体積・重量、レイヤー数と積層ピッチ、ノズル・ベッド温度、フィラメント交換回数をまとめて表示します。

ヘッダーの値だけに頼らず、すべての押し出し（E）移動を合計してフィラメントの長さを計算し直し、外壁・内壁・インフィル・サポートなど、どこにどれだけ使われたかを表示します。ヘッダーの値と大きく食い違う場合や、ヘッダーが未記入の場合は警告します。

複数のファイルやプレートをまとめて読み込むと合計も表示します。結果はコピーしたり、CSV・xlsx で保存したり、コスト計算ツールに引き継いだりできます。

使い方

  1. スライサーから G-code または .gcode.3mf を書き出し、上のエリアにドラッグ＆ドロップするか、エリアをクリックして選択します。複数のファイルを一度に選べます。
  2. ファイルごとに、概要、フィラメント別の表、フィーチャー別の表が表示されます。確認が必要な点は表の上に警告として表示されます。
  3. 下のボタンで結果をコピーしたり、CSV・xlsx として保存したりできます。「この数値でコストを計算」を押すと、重量と時間が入力された状態でコスト計算ツールが開きます。

制限と注意点

  • 造形時間は、スライサーがファイルに書き込んだ値をそのまま表示しています。このツールが独自に予測しているわけではありません。実際の時間は、フィラメント交換にかかる時間、プリンターの加速度の上限、予熱やベッドレベリングといったファームウェアの動作によって、スライサーの値とは変わります。
  • 重量は、ファイルに重量または密度が記録されている場合にのみ表示します。Cura のように長さしか記録しないスライサーのファイルでは、長さと体積のみの表示になります。フィラメント径の記録がない場合は 1.75 mm と仮定します。
  • フィーチャー別の内訳は、;TYPE: または ; FEATURE: コメントがあるファイル（Bambu Studio、OrcaSlicer、PrusaSlicer、Cura など）でのみ表示されます。開始 G-code のパージラインはスライサーのヘッダーに含まれないことが多いため、合計値がヘッダーよりわずかに大きくなる場合があります。
  • PrusaSlicer のバイナリ G-code（.bgcode）は読み込めません。スライサーで通常の G-code として書き出してください。ファームウェアリトラクション（G10/G11）や体積押し出し（M200）を使うファイルでは、合計した長さが正しくならないことがあります。
  • 通常の G-code は少しずつ読み込むため、数十 MB のファイルでも画面が固まりません。.gcode.3mf は展開してメモリに読み込むため、非常に大きなファイルはスマートフォンでは開けないことがあります。

よくある質問

スライサーの予想時間と実際の造形時間が違うのはなぜですか？

スライサーは加減速を仮定して移動時間を見積もりますが、プリンターのファームウェアの実際の動きと完全には一致しません。予熱、ベッドレベリング、フィラメント交換やパージにかかる時間も、機種や状況によって変わります。このツールはスライサーより正確に予測できるとは考えておらず、スライサーが記録した値をそのまま表示します。

ヘッダーの値と「E 移動の合計」が少し違うのはなぜですか？

ヘッダーはスライサーが計算して書き込んだ値で、合計はファイルに実際に含まれる押し出し命令を足し合わせた値です。開始 G-code のパージラインや丸め誤差のため、通常は 1% 未満の差が出ます。5% を超えて違う場合は、ファイルが編集されたか途中で切れている可能性があるため、警告を表示します。

複数プレートの合計は出せますか？

はい。プレートごとの G-code ファイルをまとめて選択するか、複数プレートを含む .gcode.3mf を読み込むと、プレートごとの結果に加えて、時間とフィラメントの合計がいちばん下に表示されます。

ファイルはサーバーに送信されますか？

いいえ。ファイルはこのブラウザー内でのみ読み込み、計算します。コスト計算ツールに引き継ぐときも、重量と時間の数値を URL の # 以降に付けて渡すだけなので、サーバーには送信されません。
