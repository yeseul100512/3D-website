출력 무게·비용 계산기

슬라이스한 파일을 넣으면 슬라이서가 계산한 무게와 시간으로 출력 비용을 계산합니다. 아직 슬라이스하지 않았다면 3D 모델로 대략적인 무게를 추정할 수 있습니다.

무게와 시간

이 모델은 구멍이 있거나 면 방향이 뒤섞여 있어 부피를 믿을 수 없습니다. 그래서 무게를 추정하지 않았습니다. 모델 검사 도구에서 문제를 확인하거나, 슬라이스한 G-code를 넣어 주세요.

슬라이스 전의 대략적인 추정입니다. 서포트, 브림, 퍼지는 포함하지 않으며 슬라이서 결과와 다를 수 있습니다.

전기요금과 장비 비용 계산에 씁니다. 1시간 30분은 1.5로 입력합니다.

재료

밀도와 가격은 흔히 쓰이는 값을 넣어 둔 기본값입니다. 고친 값은 재료별로 기억합니다. 통화는 기호만 바꾸며 환산하지 않습니다.

추가 비용(선택)

전기요금
출력 중 평균값입니다. 가정용 프린터는 보통 80~200 W입니다.
전기요금 고지서의 단가를 넣습니다. 예: 150
장비 비용(감가·소모품)
프린터 가격과 소모품 비용을 예상 사용 시간으로 나눈 값입니다.
실패 여유분
재료비·전기요금·장비 비용의 합에 더합니다. 열 번에 한 번 실패한다면 10을 넣습니다.
인건비
슬라이스, 출력 준비, 서포트 제거, 포장처럼 직접 손이 가는 시간입니다.
판매가
총 원가에 더하는 비율입니다.
판매가에서 빠져나가는 오픈마켓·결제 수수료입니다.

계산 결과

파일을 넣거나 필라멘트 무게를 입력하면 여기에 결과가 표시됩니다. 빨간색으로 표시된 입력값이 있으면 먼저 고쳐 주세요.

출력 시간이 비어 있어 전기요금과 장비 비용은 0으로 계산했습니다. 위에서 출력 시간을 입력해 주세요.

이 도구가 하는 일

필라멘트 무게와 kg당 가격으로 재료비를 계산합니다. 무게는 슬라이스한 G-code나 .gcode.3mf에서 읽는 방법이 가장 정확하며, G-code 분석기에서 넘겨받거나 직접 입력할 수도 있습니다.

아직 슬라이스하지 않은 STL·OBJ·3MF 모델은 부피와 표면적으로 무게를 대략 추정합니다. 표면 전체에 일정한 두께의 벽이 있고 나머지는 채움 비율만큼 찬다고 가정하는 단순한 계산이라, 슬라이서 결과와는 차이가 납니다.

필요하면 전기요금, 시간당 장비 비용, 실패 여유분, 인건비를 더하고, 마진과 판매 수수료를 넣어 판매가를 구합니다. 설정은 이 브라우저에 저장되며 결과는 CSV·xlsx로 내보낼 수 있습니다.

사용 방법

  1. 슬라이서에서 내보낸 G-code 또는 .gcode.3mf 파일을 넣습니다. 무게와 출력 시간이 자동으로 채워집니다. 파일이 없으면 무게를 직접 입력해도 됩니다.
  2. 재료를 고르고, 가지고 있는 필라멘트에 맞게 밀도와 kg당 가격을 고칩니다.
  3. 전기요금, 장비 비용, 실패 여유분, 인건비, 판매가가 필요하면 해당 항목을 펼쳐 값을 입력합니다. 비워 둔 항목은 계산에 넣지 않습니다.
  4. 아래 표에서 항목별 금액과 합계를 확인하고, 필요하면 CSV나 xlsx로 저장합니다.

한계와 주의할 점

  • 3D 모델로 구한 무게는 슬라이스 전의 대략적인 추정입니다. 서포트, 브림, 퍼지, 윗면·바닥면 층수 등은 반영하지 않으므로 견적에는 슬라이스한 G-code를 사용해 주세요.
  • 구멍이 있거나 면 방향이 뒤섞인 모델은 부피를 믿을 수 없어 무게를 추정하지 않습니다. 모델 검사 도구에서 상태를 확인해 주세요.
  • 재료의 밀도와 가격은 흔히 쓰이는 값을 넣어 둔 기본값입니다. 같은 재료라도 제조사와 색에 따라 달라지므로 필라멘트 사양서에 맞게 고쳐 주세요.
  • 통화는 기호와 소수 자릿수만 바꿉니다. 환율로 금액을 환산하지 않습니다.
  • 전기요금은 평균 소비전력 × 출력 시간으로 계산한 단순한 값입니다. 출력 시간은 슬라이서의 예상값이라 실제와 다를 수 있습니다. 세금과 배송비는 포함하지 않습니다.

자주 묻는 질문

STL로 추정한 무게와 슬라이서가 알려 준 무게가 왜 다른가요?

STL 추정은 모델의 부피와 표면적만 봅니다. 실제 출력물은 벽 수, 윗면·바닥면 층수, 채움 패턴, 서포트, 브림에 따라 필라멘트 양이 달라지고, 이 값은 슬라이스를 해야 알 수 있습니다. 정확한 값이 필요하면 슬라이스한 G-code를 넣어 주세요.

판매가는 어떻게 계산하나요?

총 원가에 마진(%)을 더한 뒤, 판매 수수료가 판매가의 일정 비율로 빠져나가도 그 금액이 남도록 나눕니다. 판매가 = 총 원가 × (1 + 마진) ÷ (1 − 수수료)입니다.

실패 여유분은 어디에 적용되나요?

재료비, 전기요금, 장비 비용의 합에 입력한 비율을 곱합니다. 예를 들어 열 번에 한 번 실패한다면 10%를 넣습니다. 인건비에는 적용하지 않습니다.

입력한 설정은 어디에 저장되나요?

이 브라우저의 로컬 저장소에만 저장되며 서버로 보내지 않습니다. ‘설정 초기화’를 누르면 지워집니다.
