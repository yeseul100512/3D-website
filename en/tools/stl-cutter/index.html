What this tool does

The model is cut into an evenly spaced grid along X, Y and Z. The number of pieces is worked out from the build volume minus the edge margin and the tooth depth, so a piece with its teeth never exceeds the build volume. After cutting, every piece is measured again and the table shows whether it really fits.

Cut faces can be interlocking finger joints (box joints) or flat. You set the tooth width, depth and clearance, and where two cuts cross, the teeth next to the crossing are left out, so teeth neither collide nor break off as loose slivers.

Each piece file is named after its grid position, such as X1-Y2, and an assembly map with the same labels comes with it. Download pieces one by one as STL, or everything as a ZIP.

How to use it

  1. Drop an STL, 3MF or OBJ file, or click to choose one. Its size and triangle count appear, with a warning if the mesh has holes.
  2. Enter the printer's build volume (X, Y, Z) and the edge margin.
  3. Choose whether to keep the model's orientation or rotate it for fewer pieces. Pick "Set manually" if you want to decide the number of pieces yourself.
  4. Choose the cut face and press "Split". Progress is shown and you can cancel at any time.
  5. Check the real size and fit of each piece in the table, then download the STL files or the ZIP. When assembling, follow the labels on the assembly map.

Limits and caveats

  • You cannot choose where the cuts go. They are always axis-aligned planes at equal spacing. To cut around a detail or at an angle, use the cut tool of a CAD program or slicer.
  • The model must be a closed mesh without holes. If it has open edges, duplicate faces or flipped faces, it is not cut and you are told so; nothing is repaired automatically. Fix it first with the check and repair tool on this site. Every piece comes out as a closed mesh. A file that holds several objects pushed into each other is cut with the overlapping parts left unmerged.
  • Finger joints only stop the pieces sliding in one direction along the cut. They do not resist pulling apart, so glue the parts. When a model is cut across Z, the teeth of the upper piece point down and need supports; a flat cut is the better choice there.
  • The 0.3 mm clearance is a starting value for a typical FDM printer. Depending on printer and material the fit can be tight or loose, so test with a small piece first. The tooth width is adjusted slightly so that a whole number of teeth fits the side.
  • Pieces are saved in their assembled position. Laying them flat and arranging them on the bed is done in the slicer. Units are assumed to be millimetres.
  • Large files take time and memory. Cutting 3 million triangles (a 150 MB STL) into 8 pieces took about 20 seconds on a desktop. The cutting library can use at most 4 GB of memory, so a file of about 10 million triangles (a 500 MB STL) is not cut and you get an out-of-memory message instead. On a phone, smaller files may fail too. The 3D preview and the cutting library are downloaded from a CDN on first use, so you need an internet connection (your model is not sent anywhere). The library is also used to check that a model is closed when it is small enough to need no cut.

Frequently asked questions

Will the pieces really fit my bed?

With the number of pieces on "Automatic", the grid is planned with the protruding teeth included, and after cutting each piece is measured again and marked "Fits" or "Too big" in the table. If you set the counts manually a piece can be too big, so check the table.

Will a thin plate be stood on its edge?

No. The default is "Keep my orientation", which never rotates the model. Only when you choose "Rotate for the fewest pieces" is it turned in 90° steps, and the result then states which axis went where.

Can I split 3MF or OBJ files?

Yes. STL (binary and ASCII), 3MF and OBJ are read. If a file holds several objects they are cut together as one model, and the result is saved as STL. Colours and slicer settings are not kept.

Where is the clearance applied?

On both side faces of every tooth, each by the value you enter. Tooth tips and socket floors touch without a gap, so the assembled length equals the original.

Is my file uploaded?

No. Reading, cutting and building the ZIP all happen inside this browser. The only thing downloaded is the public library used for the 3D view and the cutting.
